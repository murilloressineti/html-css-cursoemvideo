# HTML e CSS - Curso em Vídeo

Este repositório reúne os exercícios e desafios práticos que desenvolvi durante o curso de **HTML5 e CSS3** da plataforma **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

O objetivo deste projeto foi construir uma base sólida em front-end, focando em semântica, estilização moderna e layouts responsivos.

---

## 🛠 **Tecnologias e Ferramentas**

- **HTML5** (Estruturação Semântica)
- **CSS3** (Estilização e Design Responsivo)
- **Git e GitHub** (Versionamento de Código)
